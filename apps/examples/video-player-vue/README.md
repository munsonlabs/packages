# @munsonlabs/video-player - Vue example

A small Vite + Vue app with one `VideoPlayer` playing an HLS stream with English and French captions. The list under the player shows the `state-change` events as they fire.

```bash
npm install
npm run dev
```

pkg.pr.new opens this folder in StackBlitz from a pull request's comment, with `@munsonlabs/video-player` pointed at that commit's build. Every prop, event and platform is in the full demo on the docs site.

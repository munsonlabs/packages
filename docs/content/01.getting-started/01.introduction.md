**Munson Labs** publishes a small collection of standalone npm packages under the `@munsonlabs` scope.

## Packages

| Package                                                                  | Description                                                                                                                        |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| [`@munsonlabs/video-player`](/video-player/getting-started/introduction) | A standalone Vue 3 video player - native/HLS/DASH, embeds, IMA ads, and Prebid header bidding                                      |
| [`@munsonlabs/sigil`](/sigil/getting-started/introduction)               | A framework-free icon registry with a `<ml-sigil>` element - describe an SVG library or icon font, render by name, swap at runtime |
| [`@munsonlabs/shipkit`](/shipkit/introduction)                           | Shared build tooling - the `shipkit` CLI, vite configs, and tsconfigs used to build these packages                                 |

Each package is independent — installing one doesn't pull in the others. See its own section for installation and usage.

## Releasing

Packages are versioned and published via [Changesets](https://github.com/changesets/changesets), triggered from GitHub Actions on push to `main`. See the repo [`README.md`](https://github.com/munsonlabs/packages#releasing) for the full release flow.

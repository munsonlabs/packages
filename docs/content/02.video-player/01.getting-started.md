## Install

::steps

### Add the package

```bash
npm install @munsonlabs/video-player
```

### Mount a video

Import the CSS once alongside the component you use:

```vue
<script setup>
import { VideoCard } from '@munsonlabs/video-player'
import '@munsonlabs/video-player/style'
</script>

<template>
  <VideoCard
    title="Big Buck Bunny"
    src="https://cdn.jwplayer.com/videos/O5chtspP-4VHSaSK0.mp4"
    poster="https://storage.googleapis.com/gtv-videos-bucket/sample/images/BigBuckBunny.jpg"
  />
</template>
```

There's no platform prop - the platform is inferred from the shape of `src`. Swap in a YouTube, Vimeo, Brightcove, or `.m3u8` URL and the same component plays it ([all supported sources](/video-player/features/platforms)).

### Listen for playback events

Every component emits `state-change` - one stream for everything the player does, including `timeupdate` (live position) and `tap` (the user tapped the video, even with `controls="false"`):

```vue
<template>
  <VideoCard src="..." @state-change="(e) => console.log(e.type, e.currentTime)" />
</template>
```

See [Events](/video-player/api/events) for every type.

## Which component

| Component          | Use it for                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `VideoCard`        | The common case - one video, lazy by default (poster until clicked)                                                            |
| `VideoPlayer`      | Same player, always mounted immediately - no lazy placeholder                                                                  |
| `VideoStage`       | A sticky, full-width player that any `VideoCard` on the page can hand a video to, minifying to a corner pip when scrolled past |
| `VideoPlaceholder` | The poster/loading placeholder `VideoCard` uses - exported for reuse                                                           |

::callout{type="info"}
`app.use(VideoPlayerPlugin)` registers all of them, plus the headless controls, globally.
::

Paste any URL the player supports and it mounts below, running the build from this repo. Add a VAST/VMAP ad tag, `{macro}` params, or a full Prebid.js header-bidding config to exercise those paths too - or pick an example from either dropdown.

Entries are saved in this browser only, so they survive a reload and go no further.

::try-your-own
::

::note
The platform is inferred from the URL's shape, so an MP4, an `.m3u8`, a YouTube link and a Brightcove URL all go in the same box - see [platforms](/video-player/core-concepts/platforms) for the full list.
::

::warning
Ads need a real ad server response. Google's sample tags in the dropdown always fill; your own tag may legitimately return nothing, which the player treats as a no-fill and skips straight to content.
::

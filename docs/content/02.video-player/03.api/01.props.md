Accepted by `VideoCard` and `VideoPlayer`, and by each entry in `VideoStage`'s `playlist`.

## Source & presentation

| Prop          | Type                | Default  | Description                                                                                                                           |
| ------------- | ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `src`         | `string`            | -        | **Required.** Video URL or platform URI - the [platform is auto-detected](/video-player/core-concepts/platforms)                      |
| `label`       | `string`            | `''`     | Video label, shown on the placeholder and used as the accessible name                                                                 |
| `poster`      | `string`            | `''`     | Poster image URL                                                                                                                      |
| `aspectRatio` | `string`            | `'16:9'` | e.g. `'16:9'`, `'9:16'`, `'4:3'`                                                                                                      |
| `tracks`      | `CaptionTrackDef[]` | -        | WebVTT tracks: `{ src, kind?, srclang?, label?, default? }` - native path only, [see captions](/video-player/features/captions)       |
| `payload`     | `object \| string`  | `{}`     | Arbitrary data attached to every `state-change` event. A JSON string is accepted too, since a custom-element attribute arrives as one |

## Playback

| Prop           | Type                             | Default | Description                                                                                                                                                                                                                                                                                                                |
| -------------- | -------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `autoplay`     | `boolean`                        | `false` | Autoplay on mount - always starts muted, since browsers block unmuted gesture-less playback                                                                                                                                                                                                                                |
| `muted`        | `boolean`                        | -       | Force a starting mute state; unset follows the [shared audio preference](/video-player/core-concepts/autoplay-and-audio)                                                                                                                                                                                                   |
| `volume`       | `number`                         | -       | Force a starting volume (0-1); unset follows the shared preference                                                                                                                                                                                                                                                         |
| `playbackRate` | `number`                         | `1`     | Initial playback rate                                                                                                                                                                                                                                                                                                      |
| `loop`         | `boolean`                        | `false` | Start with looping on. Reactive - flipping it later is the same as calling `toggleLoop()`                                                                                                                                                                                                                                  |
| `preload`      | `'none' \| 'metadata' \| 'auto'` | -       | The native `<video preload>` attribute; unset leaves the browser default. `'none'` defers loading for MP4 and HLS alike (hls.js is held back until the first play), but not for DASH. `'metadata'`/`'auto'` leave HLS loading as normal, since hls.js buffers ahead regardless of the attribute. Embed platforms ignore it |
| `lazy`         | `boolean`                        | `true`  | `VideoCard` only: show a placeholder until clicked                                                                                                                                                                                                                                                                         |
| `playInView`   | `boolean`                        | `false` | Auto-play once at least half visible, auto-pause once not. Implies muted unless `muted` is set. Works with the lazy placeholder                                                                                                                                                                                            |
| `pin`          | `PinCorner`                      | -       | Once scrolled out of view _while playing_, pin to that corner instead of auto-pausing: `'bottom-right' \| 'bottom-left' \| 'top-right' \| 'top-left'`                                                                                                                                                                      |
| `autoStage`    | `boolean`                        | `false` | `VideoCard` only: send this video to the `VideoStage` on mount                                                                                                                                                                                                                                                             |

## UI

| Prop                       | Type           | Default | Description                                                                                                                                         |
| -------------------------- | -------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `controls`                 | `boolean`      | `true`  | `false` renders a bare `<video>` with no HUD - drive it via [methods](/video-player/api/methods) or [headless controls](/video-player/api/controls) |
| `nativeUi`                 | `boolean`      | `false` | Use the platform's own controls (YouTube, Vimeo, Dailymotion only)                                                                                  |
| `action`                   | `PlayerAction` | `null`  | Extra HUD button - a built-in (`'mute' \| 'loop' \| 'autoplay'`) or `{ icon, label, onClick }`                                                      |
| `disableTapCapture`        | `boolean`      | `false` | Disables the full-video tap-to-reveal-controls overlay                                                                                              |
| `disableKeyboardShortcuts` | `boolean`      | `false` | Disables the `Space`/`k`/arrows/`m`/`f`/`c`/`0-9` hotkeys while the player has focus                                                                |

## Ads

| Prop            | Type                     | Default | Description                                                                                                                                 |
| --------------- | ------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `adTagUrl`      | `string`                 | `''`    | VAST or VMAP ad tag URL                                                                                                                     |
| `adMacroParams` | `Record<string, string>` | -       | Fills `{macro}` tokens in whichever ad tag ends up in use, including an auto-discovered one                                                 |
| `headerBidding` | `HeaderBiddingConfig`    | -       | `{ adUnit, params?, timeoutMs? }` - runs a Prebid.js auction before the ad, [see header bidding](/video-player/features/ads/header-bidding) |

::note
If several `playInView` players are visible at once, a shared debounce lets only the last one to cross the threshold play.
::

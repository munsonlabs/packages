A player that leaves the viewport has to do _something_. By default it auto-pauses, and two props change that answer:

| Prop         | Entering view     | Leaving view                       |
| ------------ | ----------------- | ---------------------------------- |
| _(neither)_  | Nothing           | Auto-pauses                        |
| `playInView` | Auto-plays, muted | Auto-pauses                        |
| `pin`        | Nothing           | Pins to a corner and keeps playing |

They answer opposite halves of the same question, so pick the one that matches the layout: `playInView` for a feed you scroll through, `pin` for a single video you want to keep watching while reading on.

## `playInView` - feeds

Auto-plays once at least half the player is visible and auto-pauses once it isn't. Several visible players share one debounce, so only the last to cross the threshold plays. It works with `VideoCard`'s lazy placeholder, and implies muted unless `muted` is set explicitly.

::tabs
:::tabs-item{label="Vue" icon="i-vscode-icons:file-type-vue"}

```vue
<VideoCard src="..." play-in-view />
```

:::
:::tabs-item{label="Web component" icon="i-vscode-icons:file-type-html"}

```html
<ml-video-card src="..." play-in-view></ml-video-card>
```

The pattern it exists for is a TikTok-style vertical feed - each slide a bare `VideoPlayer` with a HUD built from the [headless controls](/video-player/api/controls):

```vue
<VideoPlayer v-bind="video" :controls="false" :muted="globalMuted" play-in-view @state-change="onStateChange" />

<Buffering :player="playerRef" />
<MuteButton :player="playerRef" />
<PlayButton :player="playerRef" />
<Scrubber :player="playerRef" />
```

## `pin` - mini-player

Swaps auto-pause for YouTube-style pinning: once it scrolls out of view **while playing**, it pins to that corner and keeps going, with a dismiss button. Like a mini-player, pausing it while pinned doesn't dismiss it - it stays until scrolled back into view or dismissed.

::tabs
:::tabs-item{label="Vue" icon="i-vscode-icons:file-type-vue"}

```vue
<VideoCard src="..." muted pin="bottom-left" />
```

:::
:::tabs-item{label="Web component" icon="i-vscode-icons:file-type-html"}

```html
<ml-video-card src="..." muted pin="bottom-left"></ml-video-card>
```

:::
::

::player-example{src="https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8" label="Pinned player" poster="https://m.media-amazon.com/images/S/pv-target-images/fb7afef01282cdc2d846b2343f9f3d7a785b7133729776f1aa0da6501a2e1f7b.jpg" muted pin="bottom-left" caption="Press play, then scroll past it - the player pins to the bottom-left instead of pausing."}
::

`bottom-right`, `bottom-left`, `top-right` and `top-left` are supported. A pinned box can cover content lower on the page - [`HideMarker`](/video-player/core-concepts/components#hiding-the-pinned-stage) tucks it away while a given section is in view, and `--mlv-radius` sets its corner radius.

[`VideoStage`](/video-player/features/stage-and-playlists) does the same thing for a whole playlist, minifying to a corner pip rather than pinning the card itself.

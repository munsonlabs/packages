`VideoStage` is a sticky, full-width player fed by [any `VideoCard` on the page](/video-player/core-concepts/components#which-one-to-use). There's only ever one per page.

Cards reach it over [window events](/video-player/core-concepts/components#window-events) rather than props, which is what lets a card anywhere on the page - inside an article, a sidebar, a grid - take over the stage without being wired to it.

## Playlists

Pass `playlist` - an array of the same props each card takes - and the stage tracks the current video's position within it:

::tabs
:::tabs-item{label="Vue" icon="i-vscode-icons:file-type-vue"}

```vue
<script setup>
import { VideoStage, VideoCard } from '@munsonlabs/video-player'

const videos = [
  { src: 'https://www.youtube.com/watch?v=UnktCDi-BVs', label: 'Oh my gah!' },
  { src: 'https://vimeo.com/347119375', label: 'Tears of Steel' },
]
</script>

<template>
  <VideoStage :playlist="videos" />
  <VideoCard v-for="video in videos" :key="video.src" v-bind="video" />
</template>
```

:::
:::tabs-item{label="Web component" icon="i-vscode-icons:file-type-html"}

```html
<ml-video-stage id="stage"></ml-video-stage>

<ml-video-card src="https://www.youtube.com/watch?v=UnktCDi-BVs" label="Oh my gah!"></ml-video-card>
<ml-video-card src="https://vimeo.com/347119375" label="Tears of Steel"></ml-video-card>

<script type="module">
  // `playlist` is an array, so it goes through the property rather than an attribute.
  document.getElementById('stage').playlist = [
    { src: 'https://www.youtube.com/watch?v=UnktCDi-BVs', label: 'Oh my gah!' },
    { src: 'https://vimeo.com/347119375', label: 'Tears of Steel' },
  ]
</script>
```

:::
::

Playlist entries take everything a `VideoCard` does - ad tags, `tracks`, poster, `payload`.

## Navigating

A template ref (or the element itself) exposes `playNext()`, `playPrevious()`, `hasNext` and `hasPrevious`:

::tabs
:::tabs-item{label="Vue" icon="i-vscode-icons:file-type-vue"}

```vue
<VideoStage ref="stage" :playlist="videos" />
<button :disabled="!stage?.hasNext" @click="stage.playNext()">Next</button>
```

:::
:::tabs-item{label="Web component" icon="i-vscode-icons:file-type-html"}

```js
const stage = document.querySelector('ml-video-stage')
if (stage.hasNext) stage.playNext()
```

:::
::

Skipping carries the outgoing video's [mute and volume](/video-player/core-concepts/autoplay-and-audio#playlist-skips-carry-sound-forward) forward rather than following the shared preference.

**Auto-advance** to the next entry on `ended` is built in, persisted per browser and toggled from the controls popup's "Auto" button - there's no prop for it.

## Stage-specific events

`stageopen` and `stageclose` arrive on the usual [`state-change`](/video-player/api/events) stream when the stage mounts its inner player (the first video arrives) and when it tears it down again.

::note
With a stage on the page, a `VideoCard` hands playback off entirely: `togglePlay()` selects or toggles that video on the stage, and its other control methods become no-ops, since the stage owns the player.
::

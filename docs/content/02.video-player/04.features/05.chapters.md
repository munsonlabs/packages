Chapters split a video into named sections, like the chapters of a book. The player marks where each one starts on the seek bar, shows the chapter's title while scrubbing, and lists them in the controls' **More** menu, where picking one jumps there.

They come from a WebVTT file, the same format as captions, where each cue is a section title:

```txt
WEBVTT

00:00:00.000 --> 00:00:30.000
Opening titles

00:00:30.000 --> 00:01:45.000
Morning in the meadow

00:01:45.000 --> 00:03:00.000
Big Buck Bunny wakes up
```

Pass it in `tracks` with `kind: 'chapters'`, alongside any captions:

::tabs
:::tabs-item{label="Vue" icon="i-vscode-icons:file-type-vue"}

```vue
<VideoCard
  src="https://archive.org/download/BigBuckBunny_124/Content/big_buck_bunny_720p_surround.mp4"
  :tracks="[
    { src: '/captions/bbb-chapters.vtt', kind: 'chapters', srclang: 'en', label: 'Chapters' },
    { src: '/captions/bbb-en.vtt', kind: 'captions', srclang: 'en', label: 'English', default: true },
  ]"
/>
```

## Your own chapter UI

The chapters are on the player's handle as `chapters`, a list of `{ start, end, title }` in seconds, for a chapter list or a table of contents of your own. `seek(start)` jumps to one.

::note
Chapters work on the native `<video>` path, like captions. HLS has no widely used way to carry chapters in the stream, so they come from a WebVTT file in `tracks`. Only the first chapters track is used.
::

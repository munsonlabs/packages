`@munsonlabs/video-player` plays plain MP4/HLS/DASH, YouTube, Vimeo, Dailymotion, Brightcove, and JW Player sources behind one component API, with Google IMA ad support and Prebid.js header bidding. It's a standalone package with no shared code or dependency on anything else in this repo.

`@munsonlabs/shipkit` is the shared build tooling for all `@munsonlabs/*` packages.

## What's included

- **The `shipkit` CLI**: `shipkit init`, `shipkit deploy`, `shipkit version`
- **Shared vite configs**: Vue packages and plain TypeScript libraries
- **Shared tsconfigs**: base, lib, and app configurations
- **Build utilities**: entry detection, version formatting

## Installation

```bash
npm install --save-dev @munsonlabs/shipkit vite-plus
```

## CLI commands

| Command           | Description                                      |
| ----------------- | ------------------------------------------------ |
| `shipkit init`    | Scaffold `vite.config.ts`                        |
| `shipkit deploy`  | Publish packages (local, snapshot, beta, stable) |
| `shipkit version` | Print the version derived from git               |

See [CLI](/shipkit/cli) for details.

## Shared configs

### Vite configs

| Config                                 | Use case                             |
| -------------------------------------- | ------------------------------------ |
| `@munsonlabs/shipkit/vite/vue.config`  | Vue packages, `vp pack` + `vp build` |
| `@munsonlabs/shipkit/vite/base.config` | Plain TypeScript packages, `vp pack` |

### Tsconfigs

| Config                              | Use case                                  |
| ----------------------------------- | ----------------------------------------- |
| `@munsonlabs/shipkit/tsconfig/base` | Strict ESM, `nodenext`, `noEmit`          |
| `@munsonlabs/shipkit/tsconfig/lib`  | Libraries, `bundler` resolution, DOM, JSX |
| `@munsonlabs/shipkit/tsconfig/app`  | Apps, same as lib + `isolatedModules`     |

## Exports

| Export                                 | Description             |
| -------------------------------------- | ----------------------- |
| `@munsonlabs/shipkit`                  | `shipkit` CLI binary    |
| `@munsonlabs/shipkit/vite/vue.config`  | Vue vite config         |
| `@munsonlabs/shipkit/vite/base.config` | Plain TS vite config    |
| `@munsonlabs/shipkit/vite/vue`         | Vue config fragments    |
| `@munsonlabs/shipkit/vite/shared`      | Shared config fragments |
| `@munsonlabs/shipkit/tsconfig/*`       | Shared tsconfig files   |

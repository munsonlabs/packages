## @munsonlabs/shipkit/vite/vue.config

For all Vue packages, libraries (`vp pack`) and apps (`vp build`). Both pipelines coexist in one config.

### Configuration

- `@vitejs/plugin-vue` (for `vp build`) + `unplugin-vue/rolldown` (for `vp pack`)
- `pack.entry` defaults to `{}`, set `AUTO_ENTRIES=1` to auto-detect from `package.json` exports
- `dts: { vue: true }`: DTS generation including Vue SFC types
- `vue` is always external
- `VITE_GIT_VERSION` injected via `define`
- oxlint, oxfmt, vitest with `happy-dom` — `tests/setup.ts` is picked up automatically as `setupFiles` if it exists

### Usage

```ts
import { mergeConfig } from 'vite-plus'
import type { UserConfig } from 'vite-plus'
import base from '@munsonlabs/shipkit/vite/vue.config'
import { resolve } from 'node:path'

export default mergeConfig(base, {
  pack: {
    entry: {
      index: resolve(import.meta.dirname, 'src/index.ts'),
    },
  },
}) as UserConfig
```

### Auto-entries

Set in build scripts to auto-detect from `package.json` exports:

```json
"build": "AUTO_ENTRIES=1 vp pack"
```

## @munsonlabs/shipkit/vite/base.config

For plain TypeScript libraries (no Vue). Same `AUTO_ENTRIES` pattern.

```ts
import { mergeConfig } from 'vite-plus'
import base from '@munsonlabs/shipkit/vite/base.config'

export default mergeConfig(base, {
  pack: {
    entry: { index: './src/index.ts' },
  },
}) as UserConfig
```

## Config fragments

Cherry-pick individual sections:

```ts
import { lint, fmt, test } from '@munsonlabs/shipkit/vite/shared'
import { pack, plugins } from '@munsonlabs/shipkit/vite/vue'
```

| Fragment               | Description                 |
| ---------------------- | --------------------------- |
| `vite/shared` → `lint` | oxlint configuration        |
| `vite/shared` → `fmt`  | oxfmt configuration         |
| `vite/shared` → `test` | vitest (happy-dom, globals) |
| `vite/vue` → `pack`    | unplugin-vue, dts, entry    |
| `vite/vue` → `plugins` | Vue plugins section         |

## Shared tsconfigs

Extend in `tsconfig.json`:

```json
{
  "extends": "@munsonlabs/shipkit/tsconfig/lib"
}
```

| Config          | Use case                                   |
| --------------- | ------------------------------------------ |
| `tsconfig/base` | Strict ESM - `nodenext`, `noEmit`          |
| `tsconfig/lib`  | Libraries - `bundler` resolution, DOM, JSX |
| `tsconfig/app`  | Apps - same as lib + `isolatedModules`     |

```ts
const EMOJI = {
  heart: '❤️',
  star: '⭐',
  check: '✅',
}

register('emoji', {
  resolveSync: ({ name }) => (name in EMOJI ? { tag: 'span', text: EMOJI[name] } : undefined),
})
```

```ts
interface IconSource {
  resolveSync?(request: { name; variant? }): ResolvedIcon | undefined
  resolve?(request): Promise<ResolvedIcon | undefined>
  dispose?(): void
}

interface ResolvedIcon {
  tag: string
  className?: string
  html?: string
  text?: string
}
```

`resolveSync` for anything answerable without I/O, `resolve` when you fetch, `dispose` to drop caches when unregistered. Return `undefined` for a name you don't have. Reuse `className: 'icon-svg'` for SVG output so one stylesheet rule sizes everything.

```ts
register('api', {
  resolve: async ({ name }) => {
    const res = await fetch(`/api/icons/${name}`)
    return res.ok ? { tag: 'span', className: 'icon-svg', html: await res.text() } : undefined
  },
})
```

## Caching

A source like the one above fetches on every render. Wrap it in `cached()` to get what the SVG library has: results remembered per name and variant and served synchronously from then on, one resolution shared between concurrent requests, failures retried.

```ts
import { cached, register } from '@munsonlabs/sigil'

register(
  'api',
  cached({
    resolve: async ({ name }) => {
      const res = await fetch(`/api/icons/${name}`)
      return res.ok ? { tag: 'span', className: 'icon-svg', html: await res.text() } : undefined
    },
  }),
)
```

Re-registering the name, or `unregister`, drops the cache.

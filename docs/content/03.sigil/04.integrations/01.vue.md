```vue
<script setup>
import { Sigil } from '@munsonlabs/sigil/vue'

const saved = ref(false)
</script>

<template>
  <Sigil name="heart" />
  <Sigil name="bookmark" :variant="saved ? 'active' : undefined" class="text-red-500" />
</template>
```

Same props as the element: `name`, `library`, `variant`. Everything else is forwarded to the rendered `<span>` or `<i>`.

`<Sigil>` resolves through the same registry as `<ml-sigil-icon>`, in the same order, so an override, a `use()` switch or a library registered later applies to both. Bind `variant` to state and the icon follows it.

`<ml-sigil>` is a standard custom element; render it like any tag.

::tabs
:::tabs-item{label="React" icon="i-vscode-icons:file-type-reactjs"}

```tsx
import '@munsonlabs/sigil/element'

export const Heart = ({ active }) => <ml-sigil name="heart" variant={active ? 'active' : undefined} />
```

:::
:::tabs-item{label="Svelte" icon="i-vscode-icons:file-type-svelte"}

```svelte
<script>
  import '@munsonlabs/sigil/element'
  export let active = false
</script>

<ml-sigil name="heart" variant={active ? 'active' : undefined}></ml-sigil>
```

:::
:::tabs-item{label="Plain DOM" icon="i-vscode-icons:file-type-js-official"}

```ts
import '@munsonlabs/sigil/element'

const el = document.createElement('ml-sigil')
el.name = 'heart'
button.append(el)
```

## Without the element

`watchIcon` is what `<ml-sigil>` and `<Sigil>` are built on. It resolves synchronously when it can, asynchronously otherwise, runs again whenever the registry changes, and drops results that arrive late.

```ts
import { register, watchIcon } from '@munsonlabs/sigil'
import { createIconNode } from '@munsonlabs/sigil/element?defer'

register(
  'lucide',
  {
    resolver: (name) => `https://cdn.jsdelivr.net/npm/lucide-static/icons/${name}.svg`,
  },
  { default: true },
)

const target = document.querySelector('#save-button')!

const stop = watchIcon('bookmark', { variant: 'active' }, (icon) => {
  target.replaceChildren(...(icon ? [createIconNode(icon)] : []))
})

// when the host goes away
stop()
```

`?defer` on the element import gives you `createIconNode` without defining `<ml-sigil>`, so nothing is registered on the page that you don't render yourself.

For a one-off lookup there are `getIconSync(name, query)` and `getIcon(name, query)`; `subscribe(listener)` fires after every registry change.

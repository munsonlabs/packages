| Function                                         | Description                                                                                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `register(name, config \| source, { default? })` | Adds a library. Config shape picks the kind and loads it lazily; a source is stored as is. Returns a promise that resolves when live. Re-registering replaces |
| `unregister(name)`                               | Removes a library, disposing it                                                                                                                               |
| `override(name, markup \| factory \| null)`      | Pins a name to markup, checked before any library. `null` removes. Also takes a record                                                                        |
| `use(name \| null)`                              | Sets the default library                                                                                                                                      |
| `getIconSync(name, query?)`                      | Override, else the library's `resolveSync`                                                                                                                    |
| `getIcon(name, query?)`                          | `getIconSync`, else the library's `resolve`. A source that throws yields `undefined`, with a `console.warn` in development builds                             |
| `subscribe(listener)`                            | Called after every change. Returns an unsubscribe                                                                                                             |
| `clear()`                                        | Removes everything                                                                                                                                            |

`query` is `{ library?, variant? }`.

## Helpers

| Function                                    | Description                                                                                                                                          |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `watchIcon(name, query, onIcon, registry?)` | Resolves sync-first, then async, and again on every registry change; late results are dropped. Returns `stop()`. What `<ml-sigil>` and `<Sigil>` use |
| `cached(source)`                            | Wraps a source so its answers are remembered per name and variant and served synchronously; concurrent requests share one resolution, failures retry |

## `sigil`

The shared instance behind those functions, with the same methods plus:

| Member           | Description                                 |
| ---------------- | ------------------------------------------- |
| `defaultLibrary` | Read the current default                    |
| `libraries`      | Registered names, in order                  |
| `version`        | Package version of the copy that created it |

`createSigil()` returns an isolated instance that shares nothing with the page-wide one; `Sigil` is its type.

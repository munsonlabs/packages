## `/element`

Defines `<ml-sigil-icon>` on import unless the specifier ends in `?defer`.

| Export                                  | Description                                                         |
| --------------------------------------- | ------------------------------------------------------------------- |
| `SigilElement`                          | The element. Attributes and properties `name`, `library`, `variant` |
| `defineElements(tag = 'ml-sigil-icon')` | Defines the element. Idempotent                                     |
| `createIconNode(resolved, doc?)`        | `ResolvedIcon` → element                                            |

## `/vue`

| Export  | Description                                         |
| ------- | --------------------------------------------------- |
| `Sigil` | Props `name`, `library`, `variant`; attrs forwarded |

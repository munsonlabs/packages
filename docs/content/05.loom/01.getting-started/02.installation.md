## 1. Make a kit

A kit is everything your widgets can read and do. Start with one source wrapping a composable you already have:

```js [kit.js]
import { createKit } from '@munsonlabs/loom'
import { useProduct } from './useProduct'

export const kit = createKit({
  sources: [
    {
      id: 'product',
      label: 'Product',
      primary: true,
      fields: {
        name: { type: 'string' },
        price: { type: 'string' },
        soldOut: { type: 'boolean' },
        add: { type: 'action' },
      },
      setup: (ctx) =>
        useProduct(
          {
            get product() {
              return ctx.data
            },
          },
          ctx.context.cart,
        ),
    },
  ],
  describe: (item) => item.name,
})
```

## 2. Render a widget

```vue
<script setup>
import { Widget, provideKit } from '@munsonlabs/loom'
import '@munsonlabs/loom/style.css'
import { kit } from './kit'
import productCard from './product-card.widget.json'

provideKit(kit, shop) // the kit, and the context its sources get
</script>

<template>
  <Widget v-for="(product, i) in products" :key="product.id" :definition="productCard" :data="product" :index="i" />
</template>
```

Pass `definitions` instead of `definition` and each item gets the first one [whose conditions it meets](/loom/core-concepts/matching): a widget says which data it's for in `match`, such as `[{ "path": "kind", "op": "equals", "value": "product" }]`.

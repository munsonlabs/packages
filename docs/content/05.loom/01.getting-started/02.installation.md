```bash
npm i @munsonlabs/loom
npm i @munsonlabs/loom-studio @nuxt/ui   # only where you edit widgets
```

## 1. Make a kit

A kit is everything your widgets can read and do. Start with one source wrapping a composable you already have:

```js [kit.js]
import { createKit, defineSource } from '@munsonlabs/loom'
import { useProduct } from './useProduct'

export const kit = createKit({
  sources: [
    defineSource({
      id: 'product',
      label: 'Product',
      primary: true,
      fields: {
        name: { type: 'string' },
        price: { type: 'string' },
        soldOut: { type: 'boolean' },
        add: { type: 'action' },
      },
      setup: (ctx) =>
        useProduct(
          {
            get product() {
              return ctx.data
            },
          },
          ctx.context.cart,
        ),
    }),
  ],
  describe: (item) => item.name,
})
```

## 2. Render a widget

```vue
<script setup>
import { Widget, provideKit } from '@munsonlabs/loom'
import '@munsonlabs/loom/style.css'
import { kit } from './kit'
import productCard from './product-card.widget.json'

provideKit(kit, shop) // the kit, and the context its sources get
</script>

<template>
  <Widget v-for="(product, i) in products" :key="product.id" :definition="productCard" :data="product" :index="i" />
</template>
```

Pass `definitions` instead of `definition` and each item gets the first one [whose conditions it meets](/loom/core-concepts/matching): a widget says which data it's for in `match`, such as `[{ "path": "kind", "op": "equals", "value": "product" }]`.

## 3. Edit widgets

Loom Studio is built with [Nuxt UI](https://ui.nuxt.com) and uses its components by auto-import, so the app hosting it installs Nuxt UI and scans the studio:

```js [vite.config.js]
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default {
  plugins: [vue(), ui({ router: false, scanPackages: ['@munsonlabs/loom-studio'] })],
}
```

```css [main.css]
@import 'tailwindcss';
@import '@nuxt/ui';
@source '../node_modules/@munsonlabs/loom-studio/dist';
```

```vue
<script setup>
import { LoomStudio } from '@munsonlabs/loom-studio'
</script>

<template>
  <UApp>
    <LoomStudio v-model="definition" :kit="kit" :samples="products" :context="shop" @publish="save" />
  </UApp>
</template>
```

::note
Nuxt UI only swaps in its Vue builds of `UIcon` and `ULink` for components it auto-imports, which is why the studio leaves them to your app rather than importing them itself.
::

## Built in

**Layout**

| Block    | Bindable props   | Static props                                   | Events |
| -------- | ---------------- | ---------------------------------------------- | ------ |
| `Stack`  |                  | `direction`, `gap`, `align`, `justify`, `wrap` | click  |
| `Repeat` | `items` (a list) | `limit`, `direction`, `gap`                    |        |

Both are containers. `Stack` lays its children out in a column or a row.

**Content**

| Block    | Bindable props    | Static props                           | Events |
| -------- | ----------------- | -------------------------------------- | ------ |
| `Text`   | `text`            | `variant`, `lines`, `prefix`, `suffix` | click  |
| `Image`  | `src`, `alt`      | `ratio`, `fit`                         | click  |
| `Button` | `label`, `active` | `variant`, `activeLabel`               | click  |

`Text` and `Image` render nothing when their value is empty, so an unbound field just disappears.

## Repeating

`Repeat` renders its children once per item of a list field, with two values in scope inside it:

| Path                          | Is                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `item`, `item.*`              | The current item, and the item fields its list declares                               |
| `repeat.index`                | Its position from 0                                                                   |
| `repeat.number`               | Its position from 1, for numbered rows                                                |
| `repeat.first`, `repeat.last` | Whether it's the first or last, e.g. `"if": "!repeat.last"` for dividers between rows |
| `repeat.count`                | How many items are shown, after `limit`                                               |

```json
{
  "id": "goes-with-list",
  "type": "Repeat",
  "props": { "limit": 3, "gap": "6px" },
  "bind": { "items": "product.related" },
  "children": [
    { "id": "n", "type": "Text", "bind": { "text": "repeat.number" } },
    { "id": "name", "type": "Text", "bind": { "text": "item.name" } },
    { "id": "add", "type": "Button", "props": { "label": "Add" }, "on": { "click": { "action": "product.add", "arg": "item" } } }
  ]
}
```

Passing `item` as an action's argument makes each row act on its own item. Only the innermost Repeat's `item` and `repeat` are in scope; an empty list renders nothing, so wrap the Repeat and its heading in a Stack with a _Show when_ to hide them together.

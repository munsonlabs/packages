## Built in

**Layout**

| Block   | Bindable props | Static props                                   |
| ------- | -------------- | ---------------------------------------------- |
| `Stack` |                | `direction`, `gap`, `align`, `justify`, `wrap` |

`Stack` is a container: its `children` lay out in a column or a row.

**Content**

| Block    | Bindable props    | Static props                           |
| -------- | ----------------- | -------------------------------------- |
| `Text`   | `text`            | `variant`, `lines`, `prefix`, `suffix` |
| `Image`  | `src`, `alt`      | `ratio`, `fit`                         |
| `Button` | `label`, `active` | `variant`, `activeLabel`               |

`Text` and `Image` render nothing when their value is empty, so an unbound field just disappears.

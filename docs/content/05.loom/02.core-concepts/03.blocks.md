## Built in

**Layout**

| Block      | Bindable props   | Static props                                                                                  | Events |
| ---------- | ---------------- | --------------------------------------------------------------------------------------------- | ------ |
| `Stack`    |                  | `direction`, `gap`, `align`, `justify`, `wrap`                                                | click  |
| `Box`      |                  | `background`, `padding`, `radius`, `shadow`, `border`, `direction`, `gap`, `align`            | click  |
| `Grid`     |                  | `columns`, or `minWidth` to fit as many as there's room for; `gap`, `align`                   |        |
| `Carousel` |                  | `itemWidth`, `gap`, `snap`                                                                    |        |
| `Repeat`   | `items` (a list) | `layout` (`stack`, `grid` or `carousel`), `limit`, `direction`, `columns`, `itemWidth`, `gap` |        |

All five are containers. `Box` is a surface (the theme's `surface` colour, padding and a radius by default) for cards within cards. `Carousel` scrolls sideways and snaps; each child is one slide `itemWidth` wide.

**Content**

| Block      | Bindable props     | Static props                           | Events |
| ---------- | ------------------ | -------------------------------------- | ------ |
| `Text`     | `text`             | `variant`, `lines`, `prefix`, `suffix` | click  |
| `Image`    | `src`, `alt`       | `ratio`, `fit`                         | click  |
| `Avatar`   | `src`, `name`      | `size`                                 | click  |
| `Button`   | `label`, `active`  | `variant`, `activeLabel`               | click  |
| `Link`     | `text`, `href`     |                                        | click  |
| `Badge`    | `text`             | `tone`                                 |        |
| `Rating`   | `value`            | `max`, `showValue`                     | click  |
| `Progress` | `value`, `label`   | `max`, `tone`                          |        |
| `Divider`  |                    |                                        |        |
| `Spacer`   |                    | `size`, `grow`                         |        |
| `Widget`   | `data` (an object) | `widget`                               |        |

`Text`, `Image`, `Link` and `Badge` render nothing when their value is empty, so an unbound field just disappears; `Avatar` falls back to initials from `name`, then to nothing. `Rating` fills stars to fractions (3.5 shows three and a half) in the `rating` token's colour. A `Link` with an `href` still navigates when it also runs an action; one without stays put.

## Repeating

`Repeat` renders its children once per item of a list field, with two values in scope inside it:

| Path                          | Is                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `item`, `item.*`              | The current item, and the item fields its list declares                               |
| `repeat.index`                | Its position from 0                                                                   |
| `repeat.number`               | Its position from 1, for numbered rows                                                |
| `repeat.first`, `repeat.last` | Whether it's the first or last, e.g. `"if": "!repeat.last"` for dividers between rows |
| `repeat.count`                | How many items are shown, after `limit`                                               |

```json
{
  "id": "goes-with-list",
  "type": "Repeat",
  "props": { "limit": 3, "gap": "6px" },
  "bind": { "items": "product.related" },
  "children": [
    { "id": "n", "type": "Badge", "bind": { "text": "repeat.number" } },
    { "id": "name", "type": "Text", "bind": { "text": "item.name" } },
    { "id": "add", "type": "Button", "props": { "label": "Add" }, "on": { "click": { "action": "product.add", "arg": "item" } } }
  ]
}
```

Passing `item` as an action's argument makes each row act on its own item. Only the innermost Repeat's `item` and `repeat` are in scope; an empty list renders nothing, so wrap the Repeat and its heading in a Stack with a _Show when_ to hide them together.

## Widgets inside widgets

A `Widget` block draws another widget from the library for the data bound to it, usually a Repeat's `item`. It picks the first widget whose [conditions](/loom/core-concepts/matching) that data meets, or the one whose id is in `widget`. A carousel of related stories, each drawn with its own card:

```json
{
  "id": "related",
  "type": "Repeat",
  "bind": { "items": "related.stories" },
  "props": { "layout": "carousel" },
  "children": [{ "id": "story", "type": "Widget", "bind": { "data": "item" } }]
}
```

The nested widget is a whole widget: its own sources run with its own data, its variants pick themselves, and its actions act on its own item. It shares the outer widget's kit, context, theme and scheme, and picks from the same `definitions`, so a widget rendered with only `definition` has nothing to nest. A widget never draws inside itself (a story card whose related stories would get the story card again), and nesting stops four deep.

Its nodes carry `data-nested-node-id` rather than `data-node-id`, so an editor of the outer widget sees the Widget block, not what's inside it.

## Icons

`@munsonlabs/loom/icon` exports `iconBlock`: an `Icon` block drawn by [`@munsonlabs/sigil`](/sigil), so any icon library sigil can register works. Its `name` is bindable, its `size` and `color` pick from tokens.

```js
import { register } from '@munsonlabs/sigil'
import { iconBlock } from '@munsonlabs/loom/icon'

register('lucide', { resolver: (name) => `https://cdn.jsdelivr.net/npm/lucide-static/icons/${name}.svg` }, { default: true })

createKit({ blocks: [iconBlock], ... })
```

## Your own

```js
import { defineBlock } from '@munsonlabs/loom'

export const ratingBlock = defineBlock({
  type: 'Rating',
  label: 'Rating',
  icon: 'i-lucide-star',
  description: 'Stars out of five.',
  container: false,
  props: { value: { type: 'number', label: 'Value', default: 0, accepts: ['number'] } },
  clickable: true, // its on.click can run an action
  component: Rating,
})

createKit({ blocks: [ratingBlock], ... })
```

A prop can also name a token scale (`tokenScale: 'space'`, `'radius'`, `'color'`…) so editors offer its steps; see [Tokens and themes](/loom/core-concepts/tokens-and-themes).

The component gets the resolved prop values as props, plus the node's `data-node-id`, class, style and `onClick` as attrs. Let them fall through to its root: the studio selects by `data-node-id`, and actions arrive through `onClick`. A prop's `accepts` lists the field types it can be bound to; leave it out for static-only props.

## Video

`@munsonlabs/loom/video` exports `videoBlock`, a `Video` block wrapping `VideoCard` from [`@munsonlabs/video-player`](/video-player): MP4, HLS, DASH, YouTube, Vimeo, Dailymotion, JW Player and Brightcove behind one `src`. It's a separate entry so only apps that render video load the player.

```js
import { videoBlock } from '@munsonlabs/loom/video'
import '@munsonlabs/video-player/style'

createKit({ blocks: [videoBlock], ... })
```

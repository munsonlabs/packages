A variant is a diff on the base tree, keyed by node id, with a rule for when it applies.

```json
"variants": [
  {
    "id": "sold-out",
    "label": "Sold out",
    "when": { "if": "product.soldOut" },
    "vars": { "--w-accent": "#71717a" },
    "overrides": {
      "image": { "style": { "filter": "grayscale(1)" } },
      "brand": { "bind": { "text": null }, "props": { "text": "Sold out" } },
      "add": { "hidden": true }
    }
  },
  { "id": "row", "label": "Row", "when": { "size": ["sm"] }, "overrides": { "card": { "order": ["name", "price"] } } }
]
```

## Overrides

An override merges `props`, `bind`, `on`, `if` and `style` over its base node. `null` removes the base's entry: above, the brand stops showing the data and shows fixed text. Two more:

- `hidden: true` drops the node.
- `order` lists child ids to put first; the rest follow in base order.

**Structure belongs to the base.** Adding, deleting and nesting happen there, so every variant shares node ids. An element only one variant shows lives in the base, hidden in the others.

## Rules

| `when`                 | Matches when                                                                   |
| ---------------------- | ------------------------------------------------------------------------------ |
| `if`                   | the value is truthy (`!` negates)                                              |
| `size`                 | the widget's measured width is in a bucket: `sm` < 300px ≤ `md` < 500px ≤ `lg` |
| `minWidth`, `maxWidth` | the measured width is in range                                                 |
| `scheme`               | the widget renders in `light` or `dark`                                        |

Every condition given must hold. The first matching variant wins; none matching renders the base. A variant with no rule only renders when pinned.

## Pinning

```vue
<Widget variant="row" ... />
<!-- always this one -->
<Widget variant="base" ... />
<!-- never a variant -->
```

`<Widget>` emits `variant` with the id it rendered, and its root carries `data-variant`.

::note
Size rules need the widget mounted to measure it, so on first render the base (or a data-rule variant) shows. Server-rendered pages will switch once on hydration.
::

## Functions

For editors, from `@munsonlabs/loom/editor`:

| Function                                  | Gives                                                             |
| ----------------------------------------- | ----------------------------------------------------------------- |
| `applyVariant(definition, id)`            | The plain definition a variant renders.                           |
| `variantTree(definition, id, keepHidden)` | The variant's tree, optionally with hidden nodes kept and listed. |

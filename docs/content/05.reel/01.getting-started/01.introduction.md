::warning
**Experimental.** Reel is a feasibility spike that grew a UI. It is not published to npm yet, the API will change, and it lives on the `idea/reel` branch. Everything on these pages is tested in real Chromium, WebKit and Firefox, but treat it as a preview.
::

`@munsonlabs/reel` turns the video someone is watching into a short clip they can share, without a server. It trims a range, crops it to 9:16 (or any aspect), burns the captions into the picture, stamps your logo in a corner, adds an end card that sends viewers back to the article, and writes an MP4, all with WebCodecs on the viewer's device. Containers are handled by [Mediabunny](https://mediabunny.dev); reel adds the cropping, captions, end card, codec planning and plain reasons for when a source cannot be clipped.

```ts
import { canClip, createClip } from '@munsonlabs/reel'

const check = await canClip(video)
if (check.ok) {
  const clip = await createClip({
    source: video,
    start: 42,
    end: 52,
    crop: { aspect: '9:16' },
    captions: { cues: video.textTracks[0] },
    origin: { url: location.href, title: document.title, publisher: 'Example News' },
    endCard: true,
  })
}
```

## Try it

Press the scissors in the player, pick a range, drag the crop window over the picture to reframe, export, then play or download the clip. Nothing leaves your browser. The player has `deep-link` on, so the clip's link under it reopens this page at that moment, with the range highlighted and looping. The picker's `logo` default is the reel mark, stamped on the clip and heading the end card, and **Share from the page** shows a host sharing the exported file itself, with the picker's `shareCaption` as the text.

## What you get

| Entry                      | What it is                                                                                            |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| `@munsonlabs/reel`         | `createClip`, `canClip`, `support`, `createStoryboard`, `clipLink` and the pieces they are built on   |
| `@munsonlabs/reel/vue`     | `ReelPicker`, a ready-made inline "clip this" editor in Vue, on the page's `@munsonlabs/video-player` |
| `@munsonlabs/reel/element` | `<ml-reel-picker>`, the same editor as a custom element                                               |

Mediabunny is about 157 KB gzipped, so reel is built to be loaded late: the picker imports the core on first open. The core is framework-free; the picker needs Vue and `@munsonlabs/video-player`, which most pages that clip already have.

## Install

Reel is not on npm yet. In this repo it is the `@munsonlabs/reel` workspace; elsewhere, install the branch build from [pkg.pr.new](https://pkg.pr.new) or a [local registry](https://github.com/munsonlabs/packages/blob/main/buildtools/README.md).

```bash
npm install @munsonlabs/reel
```

It depends on `mediabunny` and on `@munsonlabs/sigil`, whose Vue component draws the player's icons in the picker.

The core (`@munsonlabs/reel`) needs nothing else. **The picker needs `vue` and `@munsonlabs/video-player`**, peer dependencies it shares with the page: it works inline on the page's video-player, which is its preview. They are marked optional only so a page that uses the core alone is not asked for them.

```bash
npm install @munsonlabs/video-player vue # for the picker, /vue or /element
npm install hls.js # optional, the player's: HLS playback in Chrome, Edge and Firefox
```

With Vue, import both stylesheets once:

```ts
import '@munsonlabs/video-player/style'
import '@munsonlabs/reel/style'
```

The `/element` build puts reel's stylesheet on the page itself; it does not add the player's, since the page already has the player it clips. HLS and DASH playback is the player's: it imports hls.js or dash.js, its own optional peers, when a source needs them, and without hls.js it falls back to the browser's own HLS where there is one. Thumbnails and export never use them; they read the stream with Mediabunny.

## Requirements

A secure context (HTTPS or `localhost`) in a browser with WebCodecs `VideoEncoder`/`VideoDecoder` and `OffscreenCanvas`: current Chrome, Edge, Safari and Firefox. `canClip()` says whether a source can be clipped here and, as a stable code, why not.

## A first clip

::steps

### Ask first

`canClip` reads only the container header and never throws. Use it to decide whether to offer clipping at all.

```ts
import { canClip } from '@munsonlabs/reel'

const check = await canClip('/video/interview.mp4') // a URL, a File/Blob or a <video>
if (!check.ok) {
  console.info(check.reason, check.message) // 'unreachable', 'drm', 'embed', ...
}
```

### Make the clip

```ts
import { createClip } from '@munsonlabs/reel'

const controller = new AbortController()
const clip = await createClip({
  source: '/video/interview.mp4',
  start: 42,
  end: 52,
  crop: { aspect: '9:16', focus: 0.4 },
  onProgress: (fraction) => (progress.value = fraction),
  signal: controller.signal,
})
// clip is a Blob: 'video/mp4', H.264 video with AAC audio
```

### Give it a caption with the link back

`clipLink` is the origin URL with `#ml-t=start,end` in its hash, the link [video-player's deep links](/video-player/features/deep-links) open at that moment. Give `origin` a `player` (the player's `deep-link="<id>"`) and the link names it too, for a page with several players. Put it in the caption, and pass `origin` to `createClip` too so the MP4's metadata carries it.

```ts
import { clipLink } from '@munsonlabs/reel'

const origin = { url: location.href, title: document.title, publisher: 'Example News' }
const link = clipLink(origin, 42, 52) // https://example.com/interview#ml-t=42,52
const caption = `${origin.title}\n\n${link}`
```

### Save or share it

Web Share takes the file, the caption as `text` and the link as `url`; targets that take text post the caption with the clip. Where files cannot be shared (most desktop browsers), download instead.

```ts
const file = new File([clip], 'interview-42-52.mp4', { type: clip.type })
const data = { files: [file], text: caption, url: link }
if (navigator.canShare?.(data)) {
  await navigator.share(data)
} else {
  const a = Object.assign(document.createElement('a'), { href: URL.createObjectURL(file), download: file.name })
  a.click()
}
```

::

Or skip all four and drop in [the picker](/reel/picker/picker), which does this with a UI: its Share and "Copy caption with link" use the same link, and `shareCaption` on it holds the caption for a share button of your own.

## Load it late

Reel's core pulls in Mediabunny, about 157 KB gzipped. Import it when someone asks for a clip, not with the page:

```ts
button.addEventListener('click', async () => {
  const { createClip } = await import('@munsonlabs/reel')
  // ...
})
```

The picker does this for you.

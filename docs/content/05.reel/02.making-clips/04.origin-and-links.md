A clip that travels without its source is a dead end. Give `createClip` an `origin` and the clip says where it came from:

```ts
origin: { url: 'https://example.com/interview', title: 'The interview', publisher: 'Example News', player: 'interview' }
```

`player` is optional: the id of the player the clip came from (its `deep-link="interview"`), for a page with several players.

## The deep link

`clipLink(origin, start, end)` is the origin URL with the moment in its hash, in the one form [`@munsonlabs/video-player`'s deep links](/video-player/features/deep-links) read:

```ts
import { clipLink } from '@munsonlabs/reel'

clipLink('https://example.com/interview', 42, 52) // 'https://example.com/interview#ml-t=42,52'
clipLink({ url: 'https://example.com/interview', player: 'interview' }, 42, 52) // '…#ml-t=42,52&ml-player=interview'
clipLink('https://example.com/#/article/7', 42, 52) // 'https://example.com/#/article/7&ml-t=42,52'
```

An existing hash is kept and the parts appended with `&` (replacing any `ml-t=` or `ml-player=` it had), so a single-page app's hash route survives. A player with `deep-link` opens that link scrolled into view, at 0:42, with the range highlighted; with `ml-player`, only the player with that id does.

## Metadata

With an origin (and `metadata` not `false`), the file is tagged:

| MP4 atom       | Value                                                |
| -------------- | ---------------------------------------------------- |
| `©nam`         | `origin.title`                                       |
| `©ART`, `©pub` | `origin.publisher`                                   |
| `©cmt`         | The deep link                                        |
| `©des`         | `Clip of <title>, 42s to 52s: <link>`                |
| `©day`         | When the clip was made                               |
| `©too`         | `@munsonlabs/reel <version> (mediabunny, WebCodecs)` |

Without an origin, or with `metadata: false`, the clip has no tags at all: the source's tags are never copied. Mediabunny cannot write XMP, so there is none.

Platforms strip metadata on upload more often than not, which is why the [end card](/reel/making-clips/end-card) puts the address in the picture as well, and [the picker](/reel/picker/picker) offers a caption with the link to paste beside the clip.

## End card

`endCard` adds a silent card after the clip, faded in over its last frame: your logo, the publisher, the title, a call to action and the article's address on an accent pill. Everything defaults from `origin`, so `{}` is usually enough.

```ts
await createSplice({
  source,
  start: 42,
  end: 52,
  origin: {
    url: 'https://www.acme.news/2026/10/tides-rising',
    title: 'Tides are rising',
    publisher: 'Acme News',
  },
  endCard: { logo: 'https://cdn.acme.news/logo.svg' },
})
```

| Option       | Type                               | Default                     | Description                                    |
| ------------ | ---------------------------------- | --------------------------- | ---------------------------------------------- |
| `duration`   | `number`                           | `2.5`                       | Seconds the card stays up                      |
| `title`      | `string`                           | `origin.title`              | The headline                                   |
| `publisher`  | `string`                           | `origin.publisher`          | Drawn in the accent colour, above the headline |
| `displayUrl` | `string`                           | `origin.url`, made readable | The address shown                              |
| `cta`        | `string`                           | `'Watch the full video at'` | The line above the address; `''` hides it      |
| `logo`       | `Blob \| string \| URL`            | -                           | Loaded before the clip starts                  |
| `theme`      | `{ background?, color?, accent? }` | deep green, white, gold     | The address sits on an `accent` pill           |

By default the address is the origin's URL without its scheme, `www.`, query, hash or trailing slash, so `https://www.acme.news/2026/10/tides-rising?utm=x` shows as `acme.news/2026/10/tides-rising`. It's drawn as large as fits, and shortened in the middle if it still doesn't.

## Stamp

`stamp` draws a logo in a corner of every frame of the clip (not the end card, which has its own).

```ts
await createSplice({
  source,
  start,
  end,
  stamp: {
    logo: '/logo.svg',
    position: 'top-right',
  },
})
```

| Option     | Type                                                           | Default       | Description                   |
| ---------- | -------------------------------------------------------------- | ------------- | ----------------------------- |
| `logo`     | `Blob \| string \| URL`                                        | -             | The image                     |
| `position` | `'top-left' \| 'top-right' \| 'bottom-left' \| 'bottom-right'` | `'top-right'` | The corner                    |
| `size`     | `number`                                                       | `0.18`        | The longer side, of the width |
| `opacity`  | `number`                                                       | `0.9`         |                               |

The margins keep it clear of what TikTok, Reels and Shorts draw over a 9:16 video: the status bar at the top, the caption at the bottom, and the button rail down the right.

## Watermark

`watermark` draws a band of text, such as the site name, across the top or bottom of every frame.

```ts
await createSplice({
  source,
  start,
  end,
  watermark: {
    text: 'acme.news',
    position: 'bottom',
  },
})
```

## Logos never fail a clip

Logos load through an `<img crossOrigin="anonymous">`, so an image on another origin needs CORS headers; without them it fails to load rather than tainting the clip's canvas. A logo that can't be loaded is left out and reported through `onWarning`. SVGs are drawn at 1024 pixels on their longer side, so they stay sharp at 1080x1920.

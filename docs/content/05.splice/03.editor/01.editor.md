`SpliceEditor` is a whole "clip this" editor in Vue. It has no player of its own: the page's `@munsonlabs/video-player` is the preview.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { VideoPlayer, type PlayerHandle } from '@munsonlabs/video-player'
import { SpliceEditor } from '@munsonlabs/splice/vue'
import '@munsonlabs/video-player/style'
import '@munsonlabs/splice/style'

const src = '/video/interview.mp4'
const player = ref<PlayerHandle>()
const open = ref(false)
</script>

<template>
  <VideoPlayer ref="player" :src="src" deep-link="interview" />
  <button @click="open = true">Clip this</button>
  <SpliceEditor v-model:open="open" :player="player" :source="src" :origin="{ url: 'https://example.com/interview', player: 'interview' }" />
</template>
```

## What it does

Opening pauses the player on the moment, takes a range around it, and loops that range on the player with `setClipRange`. It hides the player's HUD and draws a 9:16 crop window over the picture, with the clip's captions, stamp and watermark previewed inside it with the export's own painters. Drag the window, or move it with the arrow keys, to reframe.

The panel has:

- **A timeline** over a filmstrip of the source: drag a handle to trim, drag the selection to slide it, click inside it or drag the playhead to seek. The handles move with the arrow keys too.
- **The player's own controls**: play, mute and captions. The captions on show are the ones burned in.
- **Toggles** for the end card and the logo stamp, when they're given, and with captions on, a choice of where they go: top, middle or bottom.
- **Export**, with progress and a cancel. The finished clip can be shared, downloaded, or its link back copied.

Closing gives the player back: the range comes off and the HUD returns. Splice's core, and Mediabunny with it, loads the first time an editor opens.

## Props

| Prop              | Type                            | Description                                                                       |
| ----------------- | ------------------------------- | --------------------------------------------------------------------------------- |
| `open`            | `boolean`                       | Shows the editor; use `v-model:open`                                              |
| `player`          | `PlayerHandle`                  | The player to clip. Or `for`, a player's id, or nest the editor inside the player |
| `source`          | `SpliceSource`                  | What to read. Defaults to the player's own file                                   |
| `src`             | `string`                        | The same as a URL, for the element's `src` attribute                              |
| `origin`          | `SpliceOrigin`                  | Where the clip comes from, for its metadata and link back                         |
| `endCard`         | `EndCardOptions \| false`       | The end card's options; `false` leaves it out and hides its toggle                |
| `stamp`           | `StampOptions`                  | The logo stamp; without it there's no logo toggle                                 |
| `watermark`       | `WatermarkOptions`              | A band of text on every frame                                                     |
| `captionPosition` | `'top' \| 'middle' \| 'bottom'` | Where the captions start out; the panel can change it. `'bottom'` by default      |
| `labels`          | `Partial<EditorLabels>`         | Rewords or translates any of the editor's text                                    |

An HLS stream played through hls.js has no file behind its `<video>` (it's a MediaSource), so pass the playlist URL as `source`. Splice reads it directly, only the smallest variant it needs.

## Events and methods

| Event         | Payload                      | When                                                             |
| ------------- | ---------------------------- | ---------------------------------------------------------------- |
| `update:open` | `boolean`                    | Opened or closed                                                 |
| `export`      | `{ blob, start, end, link }` | A clip was made                                                  |
| `error`       | `{ message, fatal }`         | `fatal` when nothing could be made; otherwise something left out |

A template ref has `show()`, `close()`, `export()`, `cancel()` and a read-only `state`. On a page without Vue, use [the web component](/splice/editor/web-component).

## Theming

The look comes from custom properties with fallbacks, set on the editor or any ancestor: `--splice-bg`, `--splice-surface`, `--splice-fg`, `--splice-muted`, `--splice-accent`, `--splice-accent-fg`, `--splice-range`, `--splice-radius`, `--splice-focus`, `--splice-error`, `--splice-font`, `--splice-scrim` (the dimming outside the crop window), `--splice-playhead` and `--splice-icon-size`.
